<h2 id="0-what-this-platform-is" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">0. What this platform is</h2>

<p class="text-sm leading-relaxed my-2">Vantage <strong>CRMP Admin</strong> is the control plane that turns Monitor 2.0 alarms into:</p>

<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>AI root-cause analysis (skill match or RAG)  </li>
<li>Independent <strong>second-AI challenge</strong> on high severity  </li>
<li>Messenger-native triage (evidence, escalate, dismiss, close, controls)  </li>
<li>Maker/checker interventions with audit + spine trail  </li>
</ol>

<p class="text-sm leading-relaxed my-2">Demo entry: <a class="underline" href="/admin">Admin Home</a> · <a class="underline" href="/admin/docs/urls">URL Catalog</a></p>

<h2 id="2-daily-path-by-role" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">2. Daily path by role</h2>

<h3 id="risk-owner" class="text-lg font-semibold mt-6 mb-2">Risk Owner</h3>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Check <a class="underline" href="/admin/alerts">Live Alerts</a> and <a class="underline" href="/admin/ai-analyses">AI Analyses</a> for BREACH/CRITICAL.  </li>
<li>Open dual-AI pack; if second AI is <code class="rounded bg-slate-100 px-1 text-[0.9em]">PARTIAL</code>/<code class="rounded bg-slate-100 px-1 text-[0.9em]">DISAGREE</code>, do not approve irreversible controls yet.  </li>
<li>Use <a class="underline" href="/admin/messenger">Demo Messenger</a> to escalate, close (accept AI), or dismiss false alarms.  </li>
<li>Approve Checker steps on <a class="underline" href="/admin/interventions">Human Intervention</a> when Ops maker-confirmed a control.  </li>
<li>Run <a class="underline" href="/admin/docs/uat">UAT Checklist</a> when validating a release.</li>
</ol>

<h3 id="risk-analyst" class="text-lg font-semibold mt-6 mb-2">Risk Analyst</h3>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Triage OPEN alerts → open AI evidence.  </li>
<li>Challenge or add context via messenger chatbot.  </li>
<li>Attach notes before escalating to Risk Owner.</li>
</ol>

<h3 id="ops-lead-analyst" class="text-lg font-semibold mt-6 mb-2">Ops Lead / Analyst</h3>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>From messenger <strong>Recommended actions</strong>, propose block / halt / leverage / widen / pause-copy.  </li>
<li><strong>Double-confirm</strong> → receive admin ref + link.  </li>
<li>If status is awaiting checker, ask Risk Owner / designated checker to approve.</li>
</ol>

<h3 id="ai-engineer" class="text-lg font-semibold mt-6 mb-2">AI Engineer</h3>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Maintain <a class="underline" href="/admin/skills">AI Skills</a>, <a class="underline" href="/admin/rag">RAG</a>, <a class="underline" href="/admin/detectors">Detectors</a>.  </li>
<li>Use <a class="underline" href="/admin/ai-admin">AI Admin</a> for settings/models (maker ≠ checker).  </li>
<li>Tune <code class="rounded bg-slate-100 px-1 text-[0.9em]">ai.second_opinion_severity</code> (default BREACH) under platform settings / AI Admin.</li>
</ol>

<h3 id="system-admin" class="text-lg font-semibold mt-6 mb-2">System Admin</h3>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Users, roles, teams, departments, settings.  </li>
<li>Review <a class="underline" href="/admin/security/ai-access">AI Access Security</a> blocklist.  </li>
<li>Monitor <a class="underline" href="/admin/audit">Audit Log</a> and <a class="underline" href="/admin/spine">Spine Log</a>.</li>
</ol>

<hr class="my-6 border-[var(--line)]" />

<h2 id="3-triage-an-alarm-desk-workflow" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">3. Triage an alarm (desk workflow)</h2>

<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Open <strong>Live Alerts</strong> or <strong>Monitor 2.0</strong>.  </li>
<li>Find an <code class="rounded bg-slate-100 px-1 text-[0.9em]">OPEN</code> / <code class="rounded bg-slate-100 px-1 text-[0.9em]">ACKNOWLEDGED</code> item.  </li>
<li>Go to <strong>AI Analyses</strong> (or wait for auto-analysis on alarm).  </li>
<li>Open the analysis → read:  </li>
</ol>
<p class="text-sm leading-relaxed my-2">   - Mode (<code class="rounded bg-slate-100 px-1 text-[0.9em]">SKILL_MATCH</code> vs <code class="rounded bg-slate-100 px-1 text-[0.9em]">RAG_REASONING</code>)  </p>
<p class="text-sm leading-relaxed my-2">   - Confidence &amp; summary  </p>
<p class="text-sm leading-relaxed my-2">   - Explanations  </p>
<p class="text-sm leading-relaxed my-2">   - Evidence vault  </p>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>If severity is <strong>BREACH</strong> or <strong>CRITICAL</strong> (or at/above <code class="rounded bg-slate-100 px-1 text-[0.9em]">ai.second_opinion_severity</code>):  </li>
</ol>
<p class="text-sm leading-relaxed my-2">   - Review <strong>Second AI challenger</strong> panel  </p>
<p class="text-sm leading-relaxed my-2">   - Read critiques, recommended improvements, alternative hypotheses  </p>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Decision rule:  </li>
</ol>
<p class="text-sm leading-relaxed my-2">   - Challenger <code class="rounded bg-slate-100 px-1 text-[0.9em]">AGREE</code> → may proceed with playbook under policy  </p>
<p class="text-sm leading-relaxed my-2">   - <code class="rounded bg-slate-100 px-1 text-[0.9em]">PARTIAL</code> / <code class="rounded bg-slate-100 px-1 text-[0.9em]">DISAGREE</code> → <strong>needs human</strong>; no irreversible control until reviewed  </p>

<p class="text-sm leading-relaxed my-2"><strong>Simulate for demo (AI Analyses page):</strong></p>
<ul class="list-disc pl-5 my-2 space-y-1 text-sm">
<li>Simulate COPY breach (skill path)  </li>
<li>Simulate EQ drawdown (RAG / WARN — challenger usually skipped)  </li>
<li>Simulate CRITICAL (forces second AI)  </li>
<li>Backfill 2nd AI challenges  </li>
</ul>

<li>Click <strong>Double-confirm…</strong> then <strong>Yes, send to Vantage admin</strong>.  </li>
<li>Thread shows admin ref + link (e.g. Interventions).  </li>
<li>If checker required, follow the system message for Checker approval.</li>
</ol>

<h2 id="5-ai-admin-maker-checker" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">5. AI Admin (maker / checker)</h2>
