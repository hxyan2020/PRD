11:T13de0,<h1 id="vantage-crmp-technical-specification-design-tsd" class="font-[family-name:var(--font-display)] text-3xl mt-2 mb-4">Vantage CRMP — Technical Specification Design (TSD)</h1>

<p class="text-sm leading-relaxed my-2"><strong>Document ID:</strong> CRMP-TSD-001  </p>

<p class="text-sm leading-relaxed my-2"><strong>§8 AI Admin</strong> and <strong>§9 Second-AI Challenger</strong> are first-class module specifications.</p>

<hr class="my-6 border-[var(--line)]" />

<h2 id="1-purpose-scope" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">1. Purpose &amp; scope</h2>

<h3 id="1-1-purpose" class="text-lg font-semibold mt-6 mb-2">1.1 Purpose</h3>
<p class="text-sm leading-relaxed my-2">Provide a single admin control plane where Risk, Ops, AI, and System operators can:</p>
<ul class="list-disc pl-5 my-2 space-y-1 text-sm">
<li>Observe Monitor 2.0 indicators / alerts</li>
<li>Run AI RCA (skills + RAG) with independent second-AI challenge on high severity</li>
<li>Triage in Demo Messenger (evidence, chat, escalate, dismiss, close, controls)</li>
<li>Enforce human gates on high-impact actions</li>
<li>Govern AI configuration via maker/checker</li>
<li>Review spine logs, risk analytics, market intel, and daily performance</li>
</ul>

<h3 id="1-2-in-scope-prototype" class="text-lg font-semibold mt-6 mb-2">1.2 In scope (prototype)</h3>
<ul class="list-disc pl-5 my-2 space-y-1 text-sm">
<li>Admin UI + SQLite persistence</li>
<li>Detectors → Alarm → AI RCA → Second opinion → Messenger / Intervention → Spine → Dashboard</li>
<li>AI Admin governance (parameters, skills, RAG, training, accuracy)</li>
<li>Risk scenario playbooks and linked timeline chains</li>
<li>Demo Messenger + Lark channel registry (mock webhooks)</li>
<li>Market Intelligence 5-minute scanner + outbox</li>
<li>Bilingual docs (EN / zh-Hant) and responsive admin shell</li>
</ul>

<h3 id="1-3-out-of-scope-production-wiring" class="text-lg font-semibold mt-6 mb-2">1.3 Out of scope (production wiring)</h3>
<ul class="list-disc pl-5 my-2 space-y-1 text-sm">
<li>Live SSO / IdP</li>
<li>Real Lark interactive cards / oneZero / wallet write adapters</li>
<li>Production LLM billing + training cluster</li>
</ul>

<hr class="my-6 border-[var(--line)]" />

<h2 id="2-system-context" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">2. System context</h2>

<pre class="my-3 overflow-x-auto rounded-lg bg-slate-900 text-slate-100 p-3 text-xs"><code>
Monitor 2.0 / Detectors ──► Alarms ──► AI RCA (Skills | RAG)

                                         │

                                         ▼

                              Second-AI Challenger (≥ BREACH)

                                         │

                                         ▼

                    Demo Messenger ◄──► Human Intervention (gates)

                                         │

                                         ▼

                              Spine Log + Risk Log + Daily Dashboard

                                         │

                                         ▼

                         Lark channels / Market Intel outbox (mock)

</code></pre>

<p class="text-sm leading-relaxed my-2"><strong>AI Admin</strong> sits beside the runtime spine: it does <strong>not</strong> execute live trading actions; it governs models, playbooks, RAG corpus, and AI parameters under dual control.</p>

<h2 id="8-ai-admin-management-page-full-specification" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">8. AI Admin Management Page — full specification</h2>

<h3 id="8-1-purpose" class="text-lg font-semibold mt-6 mb-2">8.1 Purpose</h3>
<p class="text-sm leading-relaxed my-2"><code class="rounded bg-slate-100 px-1 text-[0.9em]">/admin/ai-admin</code> is the <strong>AI control plane</strong>. Operators use it to:</p>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Observe AI health KPIs and accuracy history</li>
<li>Propose changes to AI parameters, skills, and RAG documents</li>
<li>Approve/reject those changes under <strong>maker/checker dual control</strong></li>
<li>Queue training / recalibration runs</li>
<li>Label RCA quality feedback (CORRECT / INCORRECT / PARTIAL)</li>
</ol>

<p class="text-sm leading-relaxed my-2">It is <strong>governance</strong>, not the live RCA workbench (<code class="rounded bg-slate-100 px-1 text-[0.9em]">/admin/ai-analyses</code>) and not the intervention desk (<code class="rounded bg-slate-100 px-1 text-[0.9em]">/admin/interventions</code>).</p>
