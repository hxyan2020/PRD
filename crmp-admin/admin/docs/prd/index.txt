<h2 id="1-problem-statement" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">1. Problem statement</h2>

<p class="text-sm leading-relaxed my-2">Vantage Markets operates CFD and crypto risk across Monitor 2.0 indicators, desks, and messenger escalation. Today, alarm → root cause → action is fragmented: analysts re-derive context, AI suggestions (if any) lack an independent challenge, and irreversible controls are hard to audit end-to-end.</p>

<p class="text-sm leading-relaxed my-2"><strong>We need a centralised risk management plane that:</strong></p>
<ul class="list-disc pl-5 my-2 space-y-1 text-sm">
<li>Turns Monitor alarms into explainable AI RCA  </li>
<li>Challenges high-severity RCA with a second independent AI  </li>
<li>Lets operators act in messenger (evidence, escalate, dismiss, close, controls)  </li>
<li>Enforces maker/checker and keeps AI off human-only surfaces  </li>
<li>Leaves a single spine + audit trail  </li>
<li>Gives every desk function a named admin page (home, performance, risk log, intel, org, settings, docs)</li>
</ul>

<h2 id="5-user-journeys-happy-path" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">5. User journeys (happy path)</h2>

<h3 id="5-1-high-severity-alarm-dual-ai-messenger-close" class="text-lg font-semibold mt-6 mb-2">5.1 High-severity alarm → dual-AI → messenger close</h3>
<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li>Monitor indicator breaches (e.g. COPY concentration).  </li>
<li>CRMP creates alert + AI analysis (<code class="rounded bg-slate-100 px-1 text-[0.9em]">SKILL_MATCH</code> or <code class="rounded bg-slate-100 px-1 text-[0.9em]">RAG_REASONING</code>).  </li>
<li>If severity ≥ <code class="rounded bg-slate-100 px-1 text-[0.9em]">ai.second_opinion_severity</code> (default BREACH), run <code class="rounded bg-slate-100 px-1 text-[0.9em]">crmp-challenger-v0</code>.  </li>
<li>Risk Analyst opens Demo Messenger thread; <strong>Show evidence</strong>; optionally challenges via chatbot.  </li>
<li>Risk Owner reviews primary + challenger; <strong>Close (accept AI)</strong> or escalates / requests control.</li>
</ol>

<h2 id="8-detailed-acceptance-criteria-prototype-gate" class="font-[family-name:var(--font-display)] text-2xl mt-8 mb-3">8. Detailed acceptance criteria (prototype gate)</h2>

<ol class="list-decimal pl-5 my-2 space-y-1 text-sm">
<li><strong>Skill + challenger:</strong> Simulate COPY BREACH → <code class="rounded bg-slate-100 px-1 text-[0.9em]">SKILL_MATCH</code> + Second AI panel with ≥1 HIGH improvement when challenged.  </li>
<li><strong>Threshold:</strong> WARN-only EQ simulate does <strong>not</strong> create challenge under default BREACH threshold.  </li>
<li><strong>Messenger path:</strong> Show evidence posts vault; Escalate advances path; Dismiss/Close update statuses.  </li>
<li><strong>Controls:</strong> Block account → double confirm → admin_ref; checker follow-up when required.  </li>
<li><strong>AI Admin:</strong> Distinct checker required; self-approve blocked.  </li>
<li><strong>Coverage:</strong> UAT window BREACH/CRITICAL samples 100% challenged (backfill allowed).  </li>
<li><strong>Docs:</strong> PRD/TSD/User Guide/UAT/Ecosystem/Roadmap render EN and zh-Hant; User Guide has a how-to for every left-nav page.  </li>
<li><strong>Mobile:</strong> Messenger list→thread→back works at ~390px without document overflow.  </li>
<li><strong>Pages:</strong> Login, messenger Open-in-admin, and Market Intel Scan now succeed without 404/405.  </li>
<li><strong>Knowledge tree:</strong> Domain fan-out + Enter opens a playbook.  </li>
<li><strong>Unread:</strong> New simulate/scan bumps a badge; opening the tab clears it.  </li>
<li><strong>Owner login:</strong> demo platform owner persona persists after refresh on Pages.</li>
</ol>

<p class="text-sm leading-relaxed my-2">Formal execution: <a class="underline" href="/admin/docs/uat">UAT Checklist</a> (UAT-01 … UAT-45). The pack covers every admin screen plus the full messenger loop (inbox, evidence, challenge, escalate, dismiss, close, recommended controls, sync).</p>

<h3 id="5-1-高嚴重度警報-雙-ai-messenger-結案" class="text-lg font-semibold mt-6 mb-2">5.1 高嚴重度警報 → 雙 AI → messenger 結案</h3>

<li>Monitor 指標越線（例如 COPY 集中度）。  </li>

<li>風險分析師打開示範 Messenger 執行緒；<strong>顯示證據</strong>；可選以聊天挑戰。  </li>
<li>風險負責人審主 AI＋挑戰者；<strong>結案（接受 AI）</strong> 或升級／要求控制。</li>
