Noise methods from the 12 scenarios

Must cover — and is not limited to — threshold optimisation, severity optimisation, and persistence. Also includes hysteresis, quality gates, flapping suppression, rate-limits, SEQUENCE/AND, P0 bypass, shadow, batching, dynamic multipliers, human feedback, and backtest→shadow→approve.

Core trio present: threshold · severity · persistence

  • Core · Threshold optimisation — warn/breach bands tuned to desk reality
  • Core · Severity optimisation — promote/demote WARN↔BREACH↔CRITICAL with context
  • Core · Persistence — require sustained breach across N windows before paging
  • Hysteresis — separate clear vs fire levels to stop chatter
  • Deduplication — merge sibling alerts under one parent
  • SEQUENCE / AND gates — co-fire rules across indicators
  • P0 bypass — never auto-suppress firm-critical paths
  • Shadow mode — score silently before WARN page
  • Batching — roll micro-events into a daily/config ticket
  • Dynamic multiplier — raise bands in known news windows when rails healthy
  • Data-quality gate — drop null/stale timestamps before business rules
  • Flapping suppression — ignore recover-within-window toggles
  • Notification rate-limit — cap pages per symbol/LP per minute
  • Human feedback loop — TP/FP/UNKNOWN labels drive offline retune
  • Backtest → Shadow → Approve — never hot-edit production rules
