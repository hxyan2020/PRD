# VentureScan — public URL

**Permanent site:** https://hxyan2020.github.io/PRD/venture-scan/

Deploy / refresh GitHub Pages:

```bash
cd venture-scan
npm run deploy:pages
```

The static build embeds the idea catalog and runs matching, auth, and collections in the browser (localStorage). For a Node host with SQLite APIs, use `npm run build && npm start` instead.
