# Risk Champion

Mirrored from the live Vercel deployment and extended with the **Six hours** 26-week study plan under `/study/`.

Existing Domains, Demos, Notebook, and AI helper are unchanged.

## Local

```bash
npx serve .
# open http://localhost:3000
```

## Deploy to https://risk-champion-site.vercel.app/

From this folder (with Vercel CLI logged in to the project owner):

```bash
vercel --prod --yes
```

Link to the existing `risk-champion-site` Vercel project when prompted so the URL stays the same.
