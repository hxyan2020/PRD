# Vantage 生態導入評估

**文件編號：** CRMP-ECO-001 · 原型 → 正式環境就緒評估

## 1. 總覽
CRMP 原型已驗證脊柱（Monitor → AI RCA → 第二意見 → messenger → 干預 → 稽核）。導入既有 Vantage 生態需要共用身分、真實 LP／交易適配、強化 AI 治理與分階段上線，而非一次重寫。

## 2. 必要基礎
| 基礎 | 原因 | 成熟度 |
|---|---|---|
| SSO / IdP + SCIM | 取代原型密碼 | 正式 |
| Monitor 2.0 雙向 API | 警報接入與工單回寫 | 正式 |
| LP／橋接／交易控制匯流排 | 真實停牌、槓桿、擴點 | 正式＋雙重控制 |
| Lark／Teams 互動卡片 | 取代 demo messenger | 正式 |
| Secrets 與環境隔離 | Webhook、模型金鑰 | 正式 |
| 可觀測性 | Spine SLO、AI 延遲 | 正式 |
| 資料駐留與保存政策 | 證據庫內客戶識別 | 法遵簽核 |
| IAM Maker/Checker | AI Admin 與干預 | 正式 |

## 4. 預算帶（美元，非報價）
| 階段 | 範圍 | 區間 |
|---|---|---|
| A 強化原型 | 認證、託管、UAT | $80k–$150k |
| B 生態接駁 | Monitor API、Lark、只讀 LP | $250k–$450k |
| C 受控寫入 | 雙重控制交易動作＋DR | $400k–$700k |
| D 模型營運 | 評測、挑戰 A/B、漂移 | $150k–$300k／年 |

## 5. 時程階段（以工作內容區分）
1. 基礎鎖定 — SSO、環境、資料分級、RACI。
2. 讀路徑上線 — 即時警報＋雙 AI＋通知（無自動交易）。
3. 監督寫路徑 — Maker/Checker 干預適配。
4. 優化 — 挑戰品質、情報精準度、成本。

## 6. 現況不足
- 啟發式 AI（非正式 LLM 評測閘道）。
- SQLite 單機。
- Lark 模擬投遞。
- 小螢幕導覽偏弱。
- 多品牌租戶能力有限。

## 7. 注意事項
- AI 服務主體不得擁有黑名單權限。
- 不可逆控制必須人工閘道；挑戰不同意 ⇒ 強制覆核。
- Maker/Checker 身分在 IAM 層分離。
- 寫入適配前先影子模式。
- 定義自動技能與情報推送之緊急開關。
- 證據含客戶識別前須法遵審查。
