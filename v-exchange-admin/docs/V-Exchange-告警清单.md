## 监控警报 SOP（Alex Huang · Oct 8）

与 Lark「V-exchange 监控警报SOP」对齐，包含：

1. **警报及其触发处理流程图**（事前 / 事中 / 事后；Risk、前端、BIT-perpetual、MM 造市商）
2. **1.1 警报优先级与 Risk 反应时间**（低 &lt;15min … 最高 &lt;3min）
3. **1.2 相关问题对接人**（系统/指数/标记价格、盘面/流动性、财务、价差预警及 Lark 群组）
4. **2. 盘面异常监控** — 无交易、档位深度、价差（盘口价差/偏离/插针）、限价异常（告警定义 + 原因分析 + 样例记录）
5. **3. 平台定价 / 标记价格异常监控**（Soft Xiao、Evan Bi；后续截图内容继续追加）

## 告警清单表

| 分类 | 子模块 | 告警说明 | 逻辑说明 | 告警群 |
|------|--------|----------|----------|--------|
| **盘面异常** | 无交易监控 | 最新成交价超过 x 时间未更新则触发 | 当前时间 − 上次成交时间 | Lark Webhook |
| | 档位深度监控（盘面流动性） | 针对合约盘口挂单档位数量/深度的告警 | 买盘累计深度价值 = Σ(价格×数量)；卖盘累计深度价值 = Σ(价格×数量) | |
| | 价差预警监控（盘面价差） | 监控买一与卖一价差偏离 | 价差比例 = \|卖1价 − 买1价\| / 买1价 × 100% | |
| | 价差预警监控（盘面偏离） | 买一/卖一/中间价相对指数价格偏离超过 x% | 买卖中间价 = (买1 + 卖1) / 2；相对指数价的偏离率公式 | |
| | 价差预警监控（盘口插针） | 最新成交价相对指数价偏离过大 | 价差比例 = \|最新成交价 − 指数价格\| / 指数价格 × 100% | |
| | 限价异常 | 最大买价低于卖1×x% 或 最小卖价高于买1×x%，导致无法正常挂单 | 见告警说明 | |
| **平台定价/价格异常** | 价格预警 / 定价异常 / 标记价格异常 | 监控标记价格相对指数价、最新价的偏离；账户冻结等需人工介入场景 | 价差比例 = \|标记价格 − 指数价格\| / 指数价格 × 100%；价差比例 = \|标记价格 − 最新成交价\| / 最新成交价 × 100% | |
| | 友商价差监控 | 平台与竞品（最新价/指数价/标记价）价差 | 价差比例 = \|平台最新价 − 竞品最新成交价\| / 最新成交价 × 100% | |
| **标记价格计算异常预警** | 标记价格降级 / 观察期 | 计算失败降级、进入/退出观察期 | 参考 PRD：永续合约标记价格文档 | |
| **指数价格源预警** | 指数价格源超时未更新 | 指数源在 TTL 内未更新 | 当前时间 − 上次更新时间 ≥ TTL 阈值 | |
| | 指数源变更—删除/恢复 | 源不可用、超时或偏离过大被剔除；或配置恢复 | 见告警说明 | |
| | 汇率获取失败 | USDT/USD 等汇率源失败，影响指数计算 | 主源 Kraken，备用 Binance/Bybit/OKX；Redis 缓存约 1s 更新 | |
| | 指数价格线性平滑过渡 | 平滑开始/结束阶段告警 | 见永续合约指数价格 PRD | |
| | 指数市场异常 | 仅剩单一有效数据源 | 见告警说明 | |
| | 系统资金费账户 | 账户权益异常 | Equity ≤ 0 等条件 | |
| **资金费异常** | 外部资金费率监控 | 平台与竞品资金费率差过大 | \|平台费率 − 竞品费率\| | |
| | 内部资金费率监控 | 内部费率超上下限 | 超上限/下限阈值 | |
| **DB 资金 / 账户** | DB 资金一级/二级预警 | 可用金额触及预警水位线 | 可用 = 钱包余额 − 占用初始保证金 − 委托保证金 + Σ(全仓浮动盈亏)；分级阈值 | |
| | DB 账户权益预警 | DB 账户净权益监控 | 净权益 = 账户权益 − 总注资；净权益 ≤ 阈值触发 | |
| **强平 · DB 账户告警** | DB 大额持仓 / 长时间持仓 | 持仓价值或持仓时长超阈值 | 见配置阈值 | |
| | 注资金额上限预警 | 注资金额超过上限 | 见配置 | |
| | 注资通知 / 回拨通知 | 手动或自动注资、资金回拨 | 事件触发 | |
| | DB 心跳预警 | DB 心跳断连 | DB 断连 | |
| **强平** | 大额爆仓预警 | MMR 低且仓位价值高 | MMR = 净值 / 维持保证金；MMR ≤ 1 触发爆仓；MMR &lt; 阈值且仓位价值 &gt; 阈值 | |
| | 大额爆仓后通知 | 爆仓完成后通知 | 爆仓仓位价值 &gt; 通知阈值 | |
| | ADL 异常预警 | ADL 流程异常（如接单失败、流动性无法维护） | 见告警说明 | |
| **财务报表与对账预警** | 用户快照与流水勾稽失败 | 快照与流水不一致 | 对账失败 | |
| | Broker 汇总快照与用户快照勾稽失败 | 汇总与用户层不一致 | 对账失败 | |
| | 用户/Broker 快照缺失 | 缺少快照数据 | 缺失检测 | |
| | 资金流水类型未匹配 | 流水类型无法匹配 | 类型校验 | |

**说明：** 「告警群」列在原 Lark 表中为 `https://open.larksuite.com/open-apis/...` 等 Webhook，此处不展开具体链接，部署时可按环境配置。
