价差预警监控（盘面价差） 监控买一与卖一价差偏离 价差比例 = |卖1 − 买1| / 买1 × 100% Lark Webhook
价差预警监控（盘面偏离） 买1/卖1/中间价相对指数价偏离 > x% 中间价 = (买1 + 卖1) / 2；相对指数价的偏离率 Lark Webhook
价差预警监控（盘口插针） 最新成交价相对指数价偏离过大 |最新成交价 − 指数价| / 指数价 × 100% Lark Webhook
限价异常 最大买价 < 卖1×x% 或 最小卖价 > 买1×x%，导致合约无法正常挂单 见阈值配置 Lark Webhook
平台定价/价格异常 价格预警 / 标记价格异常 标记价相对指数价、最新价偏离；计算异常需人工介入 |标记价 − 指数价| / 指数价 × 100% |标记价 − 最新价| / 最新价 × 100% Lark Webhook
友商价差监控 平台与竞品最新价/指数价/标记价对比 |平台最新价 − 竞品最新价| / 最新价 × 100% Lark Webhook
标记价格计算异常 标记价格降级告警 标记价计算失败，降级使用指数价/最新价 见【PRD】永续合约标记价格文档 Lark Webhook
进入/退出观察期 偏离达阈值进入或退出观察期 观察期阈值配置 Lark Webhook
指数价格线性平滑过渡 指数平滑开始/结束 见指数价格 PRD Lark Webhook
指数价格源预警 指数源超时未更新 指数源在 TTL 内无更新 当前时间 − 上次更新 ≥ TTL Lark Webhook
指数源变更—删除/恢复 源不可用、超时或偏离过大被剔除；或恢复 源状态机 Lark Webhook
汇率获取失败 USDT/USD 等汇率失败，影响指数 主 Kraken，备 Binance/Bybit/OKX；Redis 约 1s 缓存 Lark Webhook
指数市场异常 仅剩单一有效数据源 有效源计数 Lark Webhook
资金费异常 外部资金费率监控 平台与竞品资金费率差过大 |平台费率 − 竞品费率| Lark Webhook
内部资金费率监控 内部费率超上下限 上下限阈值 Lark Webhook
DB 资金 / 账户 DB 资金一级/二级预警 可用金额触及预警水位线 可用 = 钱包余额 − 占用初始保证金 − 委托保证金 + Σ全仓浮盈 Lark Webhook
DB 账户权益预警 DB 净权益过低 净权益 = 账户权益 − 总注资；净权益 ≤ 阈值 Lark Webhook
强平 · DB 账户 DB 大额/长时间持仓预警 持仓价值或时长超阈 配置阈值 Lark Webhook
注资/回拨通知 注资或资金回拨事件 事件触发 Lark Webhook
DB 心跳预警 DB 心跳断连，无法维护流动性 心跳超时 Lark Webhook
大额爆仓预警 MMR 低且仓位价值高 MMR = 净值 / 维持保证金；MMR ≤ 1 爆仓 Lark Webhook
ADL 异常预警 ADL 流程异常 流程失败检测 Lark Webhook
财务报表与对账 用户快照与流水勾稽失败 快照与流水不一致 对账规则 Lark Webhook
Broker 汇总与用户快照勾稽失败 汇总层与用户层不一致 对账规则 Lark Webhook
用户/Broker 快照缺失 缺少应生成的快照 缺失检测 Lark Webhook
资金流水类型未匹配 流水类型无法归类 类型映射表 Lark Webhook
