# Fatum Atlas

A browsable website cataloguing fate-telling and divination methods from around the world.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
cd fate-atlas
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Contents

- `index.html` — page structure
- `styles.css` — layout and visual design
- `app.js` — search, filters, random draw
- `data/methods.js` — curated method catalog with continent, countries, type, and sources
